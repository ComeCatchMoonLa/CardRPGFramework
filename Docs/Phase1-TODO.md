## 范围控制

开发中出现以下想法时，记录到 Phase 2 候选清单，不立即实现：

- “把三种卡牌做成通用 Effect。”
- “加一个全局事件总线方便以后扩展。”
- “先把 Buff、属性和行动队列接口留好。”
- “把 UI 改成通用框架或动态对象池。”
- “顺便增加更多敌人、卡牌类型、动画或存档。”

只有阻止当前阶段验收的问题才进入当日任务。
