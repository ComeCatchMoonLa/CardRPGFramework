# 0.5 游戏设计：遗物三钩子

> **交付目标：引入遗物栏，用三件遗物分别占住三种不同的挂钩点——开战注入（金刚杵）、改这一次施加（蛇颅骨）、改公式常数（纸鹤）——证明遗物不是 Buff，"改 Buff"也不是一种通用倍率。**
>
> 不做遗物的获取与奖励（1.0 及以后）、不做钨条 / 鸟居 / 无实体那三个更靠后的挂钩点、不做药水、不做带计数的遗物。

## 1. 设计原则

- **遗物不是 Buff。** 遗物挂在玩家的遗物栏，整场常驻，没有层数、不会衰减、不会被清除 Buff 的效果影响；它通过钩子在固定时机做事或改数值。金刚杵开战给的那 1 层力量是普通的力量 Buff，金刚杵本身不进 Buff 栏。
- **"改 Buff"分两类，落在两层。** 纸鹤改的是"虚弱倍率是多少"（规则常数），是 Rule 的事；蛇颅骨改的是"这一次施加多少层"，是施加动作上的钩子，不是 Rule。两者都不是"给某个 Buff 加一个通用 ±N%"。见 [`../../../Phase 2 扩展边界批注.md`](../../../Phase%202%20扩展边界批注.md) 第 3 节。
- 每个钩子在本版本都恰好有一件遗物用它，不留空接口。

## 2. 遗物

| 遗物 | 原版效果 | 本项目规则 | 钩子类型 |
| --- | --- | --- | --- |
| 金刚杵 | 战斗开始时获得 1 层力量 | 进入战斗、第一个玩家回合开始之前，玩家获得 1 层力量；界面 Buff 行从第一回合就显示 `力量 1` | 开战注入：在固定时机入队一个普通的施加 Buff |
| 蛇颅骨 | 每当你施加中毒时，额外施加 1 层 | 玩家作为施加方施加中毒时，这一次的层数 +1（剧毒 3 层变 4 层）。敌人施加的中毒（0.6 起可能出现）不受影响 | 改这一次施加：施加执行前修改层数 |
| 纸鹤 | 带虚弱的敌人造成的伤害减少 40% 而不是 25% | 敌人身上有虚弱且攻击的是持有纸鹤的玩家时，倍率 0.6 代替 0.75；6 点攻击变为 `floor(6 × 0.6) = 3`（无纸鹤时是 4）。玩家自己有虚弱时仍是 0.75。不给敌人加虚弱层数，也不再额外乘一层 | 改公式常数：规则读"此刻虚弱倍率是多少" |

- 遗物栏由战斗配置提供（1.0 改由 Run 提供）。默认配置同时带三件，便于一局内验收；也可以只配一件或不配。
- 界面显示遗物栏（名称即可，无图标）：`遗物：金刚杵  蛇颅骨  纸鹤`；没有遗物时显示 `遗物：无`。
- 同一件遗物不会重复持有；配置里重复算配置错误，启动时报错而不是静默合并。
- 三件遗物的名字在遗物资产里配置（与卡牌相同），不在代码里。

三件遗物之间的交互：金刚杵开战给力量走的也是"施加 Buff"，会经过蛇颅骨的钩子，但蛇颅骨只对中毒生效，所以什么都不发生——这正是钩子按 Id 判定、而不是"所有施加 +1"的意义。开战给的这 1 层力量和打出力量强化得到的力量是同一种东西、走同一条路，0.3 的卡面预览与意图预览自动把三件遗物都算进去（金刚杵：攻击卡卡面 7；纸鹤：敌人意图 3）。

**纸鹤的演示路径**：它看的是"带虚弱的**敌人**打你"。本版本敌人不会自己带虚弱，Play 里要先打出虚弱卡给敌人，再结束回合看敌人攻击从 4 变 3。0.7 蓝奴隶贩子给**玩家**上的虚弱是另一回事——那是玩家自己的攻击 ×0.75，不触发纸鹤。两条不要在讲解里混成一件事。

## 3. 战斗流程更新

```text
进入战斗：构造双方状态、牌堆、玩家遗物栏
  ↓
结算开战钩子（金刚杵：入队 +1 力量）→ 执行队列
  ↓
玩家回合开始：清格挡 → 回合开始 Buff → 恢复能量 → 抽牌
  ↓
打出卡牌：离手 → 按效果列表结算（施加 Buff 前先过施加方遗物的施加钩子）→ 按去向落堆
  ↓
结束回合 → 敌人回合开始 Buff（中毒）→ 敌人攻击（公式里虚弱倍率由目标是否持有纸鹤决定）→ 下一玩家回合
```

## 4. 本阶段不包含

- 遗物的获取、奖励、商店、移除；遗物描述文案的数值联动。
- 带计数的遗物（例如"每打出 10 张牌"）；遗物上的回合开始 / 结束钩子（本版本没有消费者）。
- 取消施加（人工制品）、施加成功后追加另一次施加（冠军腰带）。
- 与纸鹤同一种钩子的纸蛙（易伤 1.5 → 1.75）、怪异蘑菇（自己受到的易伤 1.5 → 1.25）：多做一件不多证明任何边界。
- 开战对**敌人**注入的遗物（弹珠袋：所有敌人 1 易伤）：本版本的开战钩子只碰持有者自己。
- 钨条（失去生命时少扣 1）、鸟居（未被格挡的小伤害变 1）、无实体（格挡前伤害改为 1）。
- 药水。

## 5. 验收标准

- 配置金刚杵时，战斗一开始玩家 Buff 行就显示 `力量 1`，攻击卡卡面预览为 7，打出后敌人实际掉 7（0 格挡）；不配置时卡面 6、掉 6。
- 配置蛇颅骨时，打出剧毒让敌人获得 4 层中毒；不配置时为 3 层。只配蛇颅骨（不带金刚杵）时打出力量强化仍是 2 层力量；三件同配时开战已有 1 层，打出后是 3——多出的 1 层是金刚杵给的，不是蛇颅骨加的。
- 配置纸鹤时，对敌人施加虚弱后意图显示 3、结束回合玩家实际掉 3（0 格挡）；不配置时意图 4、掉 4；玩家自己带虚弱（测试构造）时攻击伤害仍按 0.75 计算（6 → 4，不是 3）。
- 三件遗物都不出现在任何一方的 Buff 行里；界面遗物栏显示配置的遗物名称，无遗物时显示 `遗物：无`。
- 新增一件用现有钩子的遗物只需新增一个 C# 类、一份遗物配置资产并在工厂里加一行，不改 `BattleSession`；改公式常数的遗物（纸鹤一类）改对应 Rule 一处，`BattleSession` 仍不出现任何遗物 Id；新增一种**钩子**才需要在 `BattleSession` 对应时机加一处遍历。
- 配置未知遗物 Id 或同一遗物重复时，启动期在 Console 报错，战斗不初始化（与卡牌配置错误相同）。
- 0.1～0.4 的既有测试不改断言即可通过；全部 EditMode 测试通过；Console 无错误。
