# 0.4 游戏设计：消耗堆与能力牌

> **交付目标：补上第四个牌区（消耗堆），让"能力牌打出后本场不再出现"成为类型自带的行为，"消耗"关键词可以让任何类型的牌进消耗堆。力量强化改为能力牌，新增坚不可摧（带消耗的技能）当对照。**
>
> 不做虚无 / 固有 / 保留关键词、不做从消耗堆取回卡牌、不做"每当消耗一张牌"的触发、不做状态牌 / 诅咒。遗物是 0.5。

## 1. 设计原则

- **类型决定去向。** 能力牌打出后进消耗堆，是类型的默认行为，不需要每张都写"消耗"；攻击 / 技能默认进弃牌堆；任何类型只要带"消耗"关键词就进消耗堆。这是原版规则，见 [`../../../详细游戏设计文档参考/卡牌类型与关键词.md`](../../../详细游戏设计文档参考/卡牌类型与关键词.md) 第 1～2 节。
- **去向是牌自己的事。** 0.2 把"打出后发生什么"交给效果列表，本版本把"打出后去哪"交给类型与关键词；`BattleSession` 只问结果，不按牌分支。
- 类型与关键词必须同时有对照：力量强化（能力，类型默认消耗）和坚不可摧（技能 + 消耗关键词）缺一个就证明不了"两条路径落到同一个牌区"。

## 2. 卡牌与牌区

### 2.1 卡牌变更

| 卡牌 | 变更 | 类型 | 费用 | 效果 | 打出后去向 |
| --- | --- | --- | ---: | --- | --- |
| 力量强化 | 类型改为能力牌（原版 Inflame） | 能力 | 1 | 自身获得 2 层力量 | 消耗堆（类型默认） |
| 坚不可摧 | 新增（原版 Impervious） | 技能 | 2 | 自身获得 30 点格挡 | 消耗堆（带"消耗"关键词） |

其余卡不变。牌组从 0.2 的 17 张扩充为 **18 张**（新增 1 张坚不可摧）。

### 2.2 牌区规则

四个牌区：抽牌堆、手牌、弃牌堆、**消耗堆**。

- 抽牌堆为空时只把弃牌堆洗回，消耗堆本场永不回洗。
- 回合结束弃掉剩余手牌时，带"消耗"关键词的牌也是**进弃牌堆**，不是消耗——"消耗"只在被打出时生效。
- 打出中的牌（离手到落堆之间）不在任何牌区，与 0.2 一致；结算完按去向落入弃牌堆或消耗堆。
- 界面显示三个牌堆的数量：抽牌 / 弃牌 / 消耗。
- 战斗结束后消耗堆随本场战斗一起消失（1.0 的 Run 会从局外牌组重新构造下一场的牌堆）。

对局例子：牌组里唯一一张力量强化打出后，之后无论多少次重洗都不会再抽到它；界面消耗堆数量为 1。

## 3. 战斗流程更新

```text
打出卡牌：校验 → 扣能量 → 离手 → 按效果列表结算 → 按类型 / 关键词落入弃牌堆或消耗堆 → 胜负判定
  ↓
结束回合：剩余手牌全部进弃牌堆（含带消耗关键词的牌）
  ↓
抽牌堆为空：只把弃牌堆洗回
```

其余流程与 0.3 一致。

## 4. 本阶段不包含

- 虚无、固有、保留、不能打出等其它关键词；状态牌、诅咒。
- "每当消耗一张牌时……"的触发；从消耗堆取回卡牌；被效果消耗（"消耗手牌中一张牌"）。
- 遗物（0.5）。
- 消耗堆的可视化列表（只显示数量）。

## 5. 验收标准

- 打出力量强化后，它进入消耗堆，之后整场不再被抽到；抽牌堆为空时重洗只洗回弃牌堆。
- 打出坚不可摧获得 30 点格挡，并进入消耗堆；回合结束时手里未打出的坚不可摧进弃牌堆。
- 界面三个牌堆数量正确；打出能力牌后消耗堆数字 +1。
- 新增一张消耗牌只需在 `CardData` 上勾"消耗"，不改 C# 代码。
- 0.1～0.3 的既有测试不改断言即可通过；全部 EditMode 测试通过；Console 无错误。
