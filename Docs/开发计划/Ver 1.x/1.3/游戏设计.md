# 1.3 游戏设计：战后三选一

> **交付目标：奖励抽卡发生在战斗页之外。** 胜利 → `ApplyResult` 写回 → 奖励页 → `AddCard` / 跳过 → 地图或结束。奖励 RNG 用 `g(runSeed, rewardIndex)`，与战斗 `Random` 无关。`AddCard` 在 1.0 已有，本版只负责抽出三张并让玩家选。第三场通关后 `IsCleared` 已为 true，仍走奖励页再去结束页。
>
> 不做遗物奖励、金币奖励、卡牌移除与升级。
>
> 总设计见 [`../游戏设计.md`](../游戏设计.md) 第 5、8 节。进入本版前补技术设计与 TODO。**短 Run 完成定义在总设计第 8 节，本版完成后才勾。**

## 1. 设计原则

- **奖励页不是战斗页。** 三张候选卡复用 `CardDescriptionFormatter.Format(CardDefinition)`（基础数值、不依赖 Controller），没有战斗就没有预览。
- **奖励 RNG 独立于战斗洗牌。** 同一开局、同一局外操作序列 → 相同候选；出了多少牌、重洗几次不影响。
- 选一张加入牌组，或跳过。选完立刻在顶栏看到牌组张数 +1。

## 2. 本版做 / 不做

| 做 | 不做 |
| --- | --- |
| 胜利 → `ApplyResult` → 奖励页 → `AddCard` / 跳过 → 地图或结束 | 遗物奖、金币奖 |
| 奖励池 = 可获得卡（排除打击 / 防御）；随机三张不同 | 升级、移除 |
| `g(runSeed, rewardIndex)` 派生抽取 | 把奖励随机接到战斗 `Random` 上 |
| 选一张 `AddCard` 或跳过 | 商店、休息 |

奖励池与总设计第 5 节一致：痛击 / 双击 / 剑柄打击 / 坚不可摧 / 力量强化 / 剧毒 / 虚弱 / 易伤 / 治疗。

## 3. 验收标准

对照总设计第 8 节；勾那一节的前提是本版完成。

- 奖励页三张互不相同且不含打击 / 防御；跳过后牌组张数不变。
- 第一场胜利后选的卡在第二场能抽到。第三场胜利写回后仍能选卡入组，然后再去结束页。
- 固定种子下两局的洗牌顺序与奖励候选一致；出牌与重洗次数不改变候选。
- 战斗页内没有选卡控件。
- 0.x～1.2 测试不改断言通过。
