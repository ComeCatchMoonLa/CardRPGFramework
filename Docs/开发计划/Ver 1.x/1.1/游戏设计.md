# 1.1 游戏设计：Run 壳与战斗接入

> **交付目标：第一次能从开始页点进去，自动连打三场到结束页。** 流程层创建 / 销毁 `BattleSession`；战斗页只管局内；顶栏常驻。还没有地图，胜利后直接下一场。
>
> 不做地图、奖励、选卡。Play 只走 `RunConfig`；`TestScene` 改成 Run 壳；单场调试删除；`BattleConfig` 不再开战。
>
> 总设计见 [`../游戏设计.md`](../游戏设计.md)。1.0 已完成。技术设计 / TODO 已转正，无未拍的 **[待确认]**。

## 1. 设计原则

- **战斗页只管局内。** 选下一场、结束页、再来一局都是流程的事。局内命令交给 `RunController`，不直接打 `BattleController`。
- **Session 生命周期在流程层。** 唯一产品侧创建 / 销毁 Session 的地方是 `BattleController.Begin` / `DiscardSession`；不把 `RunState` 传入 Session。
- Start / 顶栏 / Result 与 Combat 同一刀：没有其它页也不成壳，不拆成单独版本。
- **结束写回是单通道。** 每个结束 `Phase` 只 `ApplyResult` 一次。场间胜利不遮罩、立刻下一场；通关或失败才上结束页。不靠每帧读 `Phase`。

## 2. 本版做 / 不做

| 做 | 不做 |
| --- | --- |
| `RunController` 持有 `RunState`、唯一一份 `RunConfig`、当前页 | 地图页、`NodeType` |
| 顶栏：生命 / 金币 / 牌组张数 / 遗物；战斗中生命跟局内 | 奖励页、三选一 |
| Start / Combat / Result 三页显隐 | 改 `BattleSession` 构造签名 |
| 胜利自动下一场；最后一场胜利或失败 → 结束页 | 空商店、分支图 |
| 场间无结束遮罩；通关 / 失败切 Result；删除 `EndScreenView` | 事件总线；单场旁路 / `BattleConfig` 开战；`Update` 轮询结束 |

```text
开始页：[开始一局] → StartRun
  ↓
RunConfig.TryValidate → CreateRunState
  ↓
战斗页：Begin(BattleInput) → 玩家点牌 / 结束回合（只打 RunController）
  ├─ Defeat → ApplyResult(false, …) → 结束页（失败）
  └─ Victory → ApplyResult(true, 局内生命)
        ├─ 尚未通关 → 立刻 Begin(CreateBattleInput()) 下一场（无遮罩）
        └─ 已通关 → 结束页（通关）
  ↓
结束页：[再来一局] → Restart（丢掉 RunState 与 Session）→ 开始页
```

## 3. 顶栏

战斗中生命显示局内值（Run 值在出战斗时才写回，两者战斗中允许不同，顶栏跟局内）。其它页读 `RunState`。这是设计，不是 bug。

起始遗物显示名来自 `RunConfig` 上的 `RelicData`，由 `StartRun` 在第一次 `Begin` 前写入 `BattleController` 字典。Start 页点开始前没有 `RunState`，**不读 `RunConfig`**：遗物写 `遗物：无`，生命 / 金币 / 牌组不要预填 80 / 0 / 10。再来一局清空字典。

## 4. 验收标准

- 从开始页点一次进入，连打三场到结束页，全程不回 Editor（本版没有奖励页，胜利后自动下一场）。
- 场间胜利无结束遮罩、立刻下一场；通关或失败才切结束页。删除 `EndScreenView`。
- 第二场开局生命等于第一场结束时的生命（Play 验收；场间必须先写回再开战）。起始遗物三场都在遗物栏且生效。
- 战斗页内没有选卡或进下一场的控件；顶栏在 Start / Combat / Result 之间切页时始终存在。
- 中途死亡进入失败结束页；再来一局后 Run 从初始状态开始，Combat 在下一轮 `Begin` 前不可点；Start 顶栏 `遗物：无`。
- `BattleController.Awake` 不再 `new BattleSession`；产品侧创建点只剩 `Begin`；场景不再用 `BattleConfig` 开战。
- 产品侧 `ApplyResult` 只在流程层、每节点一次；不靠每帧读 `Phase`。
- 漏配（空牌组、不是三场敌人）点开始进不了战斗。
- 0.x 与 1.0 测试不改断言通过。
