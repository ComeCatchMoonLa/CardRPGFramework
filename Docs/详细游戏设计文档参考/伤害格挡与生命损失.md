# 伤害、格挡与生命损失

> **一句话：不是所有「掉血」都走同一条路。攻击伤害吃力量/虚弱/易伤并被格挡；生命损失两者都不吃；荆棘不吃公式但被格挡。格挡前、格挡后、真正扣血前是三个不同挂钩点，不能合成一个「最终伤害」。**

## 1. 三种伤害

| 类型 | 玩家能想到的来源 | 力量 / 虚弱 / 易伤 | 被格挡 | 触发荆棘 / 镀层等「被攻击」 |
| --- | --- | --- | --- | --- |
| 攻击伤害 | 攻击牌、敌人攻击意图 | 是 | 是 | 是 |
| 生命损失 | 中毒、部分卡牌自残、悔恨 | 否 | 否 | 否 |
| 荆棘伤害 | 荆棘、部分反伤遗物 | 否 | 是 | 否（避免无限反弹） |

需求：每一种造成「数字掉在某人身上」的效果必须声明自己是哪一类。未声明就无法决定格挡和无实体怎么处理。

治疗不是伤害。治疗只加当前生命，不超过最大生命，不经过格挡，不触发钨条（钨条管的是失去生命）。

## 2. 攻击伤害公式

```text
最终值 = floor( (基础值 + 力量) × 虚弱倍率 × 易伤倍率 )
```

规则：

- 全程用小数算，**只在最后向下取整一次**。不要每乘一次取整。
- 加法永远在乘法前面。力量是加法，虚弱/易伤是乘法。
- 乘法顺序：先算攻击方（虚弱），再算受击方（易伤）。有纸鹤/纸蛙/蘑菇时，乘的是被遗物改过的常数，不是再叠一层。
- 基础值印在牌上或意图上，是整数。
- 力量取**攻击发起方**当前层数（可为负）。虚弱看发起方有没有（倍率与层数无关）。易伤看**受击方**有没有。

默认倍率：虚弱 0.75，易伤 1.5，没有则 1。遗物改的是这些常数：

| 修正 | 虚弱倍率 | 易伤倍率（对谁） |
| --- | --- | --- |
| 无 | 0.75 | 1.5 |
| 纸鹤 | 0.60 | 不变 |
| 纸蛙 | 不变 | 1.75（你打易伤敌人） |
| 怪异蘑菇 | 不变 | 1.25（你被易伤时挨打） |

腕刃等「0 费攻击 +4」加在基础值上，仍在力量之前或并入基础值，不得放到取整之后。

公式结果可以为 0（高虚弱、负力量）。下面两件事不要写成同一句：

- **算完 >0、格挡吃光**：原版仍算一次「被攻击」，荆棘会触发。
- **算完就是 0**：不要默认仍进「被攻击」、仍触发荆棘。实现该交互前单独核对，不要拿全格挡那条去套。

生命损失即使数字很大也不触发荆棘。

## 3. 格挡

### 3.1 获得格挡

```text
卡牌格挡 = floor( (基础值 + 敏捷) × 脆弱倍率 )      ← 只对打出卡牌直接获得的格挡
其它来源 = 基础值                                    ← 能力、遗物、药水、充能球：原样加
```

- **敏捷和脆弱只作用于「打出卡牌直接获得的格挡」**（防御、耸肩、盔甲等）。金属化、镀层护甲、无惧疼痛、可塑、残像、遗物（奥利哈钢）、药水（格挡药水恒 12 / 24）、冰霜球获得的格挡**都不吃**敏捷和脆弱（wiki.gg Block：*Dexterity, Frail and No Block do not work with Relics, Potions or Orbs*；金属化页明确 *unaffected by Frail, Dexterity*）。「获得格挡」不是一条统一公式，需求上每个格挡来源要声明自己是不是「卡牌格挡」。
- 敏捷取获得格挡的那一方，可以为负（卡牌格挡最低 0）；脆弱有则 ×0.75（层数不放大），只在最后取整一次。
- 加到当前格挡上，没有上限（原版上限 999）。
- 已经存在的格挡不会因为后来敏捷变化而重算。

### 3.2 格挡何时清零

默认在**该生物自己的行动开始**清零，不是行动结束。所以玩家用防御牌获得的格挡，能挡住紧接着的敌人攻击。

例外（流程开关，见 [回合时序与能量.md](回合时序与能量.md) 与 [Buff与Debuff.md](Buff与Debuff.md)）：

- 路障：自己的行动开始不清格挡。
- 模糊：下一次本该清的时候不清。
- 冰淇淋管能量，不管格挡。

### 3.3 格挡怎么吃伤害

只吃攻击伤害和荆棘伤害。多段攻击每一跳单独用当前格挡吃，吃完再进行下一跳。

```text
这一跳：先算最终攻击伤害 →（无实体可能改为 1）→ 与当前格挡比较
  伤害 ≤ 格挡：格挡减少那么多，生命不变
  伤害 > 格挡：格挡归零，差额进入「即将失去生命」
```

生命损失整段跳过本小节。

## 4. 整条管线（挂钩点地图）

从「产生一个数字」到「当前生命变化」：

```text
① 产生基础值（牌面 / 意图 / 效果写死的数）
    ↓
② 攻击公式：+力量，×虚弱，×易伤，取整     ← 仅攻击伤害；生命损失、荆棘跳过
    ↓
③ 格挡前最终修正                              ← 无实体：改为 1。凡是还没进格挡的伤害数字都经过（含荆棘）
    ↓
④ 格挡吸收                                    ← 攻击与荆棘；生命损失跳过
    ↓
⑤ 格挡后观察                                  ← 鸟居：未被格挡的攻击伤害 ≤5 → 1
    ↓
⑥ 即将失去生命                                ← 先缓冲（值 >0 则变 0 并减层），再钨条 -1
    ↓
⑦ 当前生命减少（可以减到 0）
    ↓
⑧ 若当前生命 ≤0：致死改写（仙灵、蜥蜴尾巴）；否则死亡
```

反例（用来验收挂钩点有没有挂错）：

| 场面 | 错误挂法 | 正确结果 |
| --- | --- | --- |
| 50 攻击，10 格挡，受击方无实体 | 把无实体挂在 ⑥，变成先吃格挡剩 40 再改成 1，掉 1 血 | ③ 处 50→1，④ 被 10 格挡吃掉，掉 0 血 |
| 荆棘 5，受击方无实体、无格挡 | 荆棘跳过 ③，掉 5 血 | ③ 处 5→1，掉 1 血 |
| 中毒 5，受击方 10 格挡 | 中毒走 ④，格挡变成 5 | 中毒是生命损失，格挡仍 10，生命 -5（若无钨条） |
| 中毒 1，持有钨条 | 钨条挂在 ③ 当无实体用 | ⑥ 钨条处 1-1=0，不掉血；格挡不动 |
| 1 点未格挡，缓冲 + 钨条 | 钨条先把 1 削成 0，缓冲不掉 | 缓冲先看到 1 并消耗一层，再轮到钨条 |
| 未被格挡的 5 点攻击，鸟居 | 鸟居挂在 ③，先变成 1 再格挡 | ⑤ 处 5→1，若此时无格挡则进入 ⑥ |

靴子是输出侧对称物：你造成的、格挡后的攻击伤害若 ≤4 则改为 5。它不保护你挨打。因为它排在受击方的 ③ 和 ④ 之后，**你打无实体敌人时，1 会被靴子抬回 5**（wiki.gg The Boot：*playing an Attack against an Intangible Nemesis will deal 5 damage instead of the normal 1*）；算完就是 0 的攻击不会被抬到 5。做靴子时单独按这两条验收。

## 5. 多段攻击

每一跳都是一次完整的 ①→⑦，不是「加总后再格挡一次」。

后果（都是需求，不是优化选项）：

- 4 段各 3 点，对 5 格挡：第一跳吃 3 格挡，第二跳吃完剩余 2 并扣 1 血，后面两跳全扣血。
- 无实体下 4 段攻击 = 4 次「改为 1」，4 格挡可以全部挡掉；若错误地先加总再改成 1，会变成只掉 1 或 0，和原版手感相反。
- 荆棘每跳触发一次。双持打带 3 荆棘的敌人，玩家吃 2 次 3 点荆棘（再走荆棘伤害管线，可被玩家格挡）。

钢笔尖「第 10 次攻击翻倍」计数的是打出一张攻击牌，翻倍的是这一次打出里的每一跳。

## 6. 生命损失与即将失去生命

生命损失从 ① 带一个整数来，跳过 ② 和 ④，但仍经过 ③（无实体）和 ⑥（先缓冲，再钨条）。

「即将失去生命」是**唯一**让当前生命变少的入口。无论攻击溢出还是中毒，最后都要进这里。这样钨条只需生效一次。

⑥ 的内部顺序写死为 **缓冲在钨条之前**：

- 值 >0 且有缓冲 → 改为 0 并消耗 1 层，再问钨条（此时已是 0）。
- ④ 之后已经是 0（全格挡）→ 根本不问缓冲，也不问钨条。这才是「没扣血就不消耗缓冲」。
- 不要把「钨条把 1 削成 0」当成上一句。1 点未格挡时缓冲仍会被吃掉。

最大生命减少（寄生等）不是本条管线；它改上限，必要时把当前生命钳到新上限。

## 7. 致死与战斗结束

先完成 ⑦（当前生命减少，**可以减到 0**），再进入本节约定。不要在扣血前拦截成「根本不掉到 0」。

当前生命已经 ≤0 时、死亡判定前：

1. 问仙灵药水、蜥蜴尾巴等致死改写（见 [药水.md](药水.md)、[遗物.md](遗物.md)）。改写成功则生命变成指定值，战斗继续。
2. 否则该生物死亡。玩家死亡 = 失败。敌人死亡：若场上没有存活敌人 = 胜利，**立即**结束，不再开始任何新的敌人行动；正在结算的这一跳可以完成到 ⑦。

「击杀后立刻停掉这张牌已排好的后续跳数」是**本项目的简化**：原版里当前这张牌已入队的后续伤害 Action 通常还会跑完（对已死目标不产生效果，玩家看不出差别）。两种做法结果一致，但不要把本项目的写法说成原版队列语义。

中毒在阵营行动开始把最后一个敌人打死，则本轮敌人不再出手。这是胜负判定时点，不是伤害公式的一部分。

## 8. 预览数字

玩家打出前看到的伤害/格挡数字、敌人意图上的伤害数字，必须用**此刻**的公式算一遍（含力量、虚弱、易伤、纸鹤类常数）。不要求预览鸟居、钨条、无实体的全部嵌套（原版意图也不预览钨条），但攻击牌上的预览应与打出后 ② 的结果一致，否则无法决策。

无实体敌人的意图仍显示「将打 12」，实际经过 ③ 会变成 1 再被格挡。若本项目做无实体，需要决定意图是显示改写前还是改写后——原版显示改写前的意图数字，实际挨打是 1。需求上允许「意图显示未改写值」，但结算必须改写。

## 9. 对本项目的需求分析结论

- 攻击与生命损失两条路径从第一天就要分开，不能都调用同一个「扣血并吃格挡」。
- 格挡前最终修正、格挡后观察、即将失去生命是三件不同的事；无实体、鸟居、钨条各占一个。
- 多段 = 多次完整管线。
- 公式顺序固定：加力量 → 乘攻击方倍率 → 乘受击方倍率 → 取整。不要做成可配置的通用规则链来「证明扩展性」。
- 「获得格挡」分两路：卡牌格挡吃敏捷 / 脆弱，能力 / 遗物 / 药水的格挡原样加。金属化是第一个会踩到这条的消费者。
