# Buff 与 Debuff（能力）

> **一句话：能力是挂在某个生物身上的数据（谁、什么、几层、极性）。「到点扣血」是它引用的触发；「打人加伤害」是它参与的数值修正。能力自己不直接改战斗，时机到了才产生一次效果或改一次计算。**

本文描述《杀戮尖塔》一代玩家能观察到的能力规则。原版内部叫 Power。

## 1. 玩家能看见什么

每个生物有一份能力列表。玩家必须能读到：

- 名称与极性（有利 / 有害）
- 当前层数（没有层数的旗标型可以只显示有无）
- 一句效果说明（例如「攻击伤害 +N」或「再过 N 回合消失」）

遗物栏、手牌关键词、药水槽**不是**能力列表。金刚杵开战给的那 1 层力量会进能力列表；纸鹤整场待在遗物栏，永不进能力列表。

## 2. 极性：Buff 还是 Debuff

极性是施加规则的一部分，不是美术标签。

| 极性 | 典型例子 | 谁在乎 |
| --- | --- | --- |
| Buff | 力量、敏捷、荆棘、金属化、路障、人工制品、缓冲、无实体 | 不会被人工制品拦截 |
| Debuff | 虚弱、易伤、脆弱、中毒、纠缠、力量下降、敏捷下降、混乱 | 人工制品取消**下一次** Debuff 施加；虐待倾向（Sadistic Nature）在你成功施加 Debuff 时打伤害 |

判定要点：

- **中毒是 Debuff**。人工制品会挡住这次上毒。
- **给对方加负层力量（缴械）是 Debuff 施加**。人工制品会挡住，这次力量不变。
- **给自己加正层力量是 Buff**。人工制品不理它。
- 极性跟「对所有者好不好」大体一致，但以规则表为准，不按玩家直觉现场猜。

## 3. 层数的两种语义（禁止混用）

一个层数字段在原版里叫 `amount`，承载两种完全不同的意思：

| 语义 | 层数表示 | 效果强度与层数 | 典型 |
| --- | --- | --- | --- |
| 强度型 | 效果有多强 | 成正比：3 力量 = 攻击 +3 | 力量、敏捷、中毒、荆棘、金属化 |
| 回合型 | 还剩几段持续时间 | **无关**：1 层虚弱和 3 层虚弱都是伤害 ×0.75，只是持续更久 | 虚弱、易伤、脆弱 |

两条禁令：

- 虚弱 / 易伤 / 脆弱**按「有或没有」乘固定倍率**，不要按层数把 0.75 变成 0.75^N 或 0.75×N。
- 中毒那种「结算时自减 1」**不能**拿去给虚弱用。中毒减层发生在所有者（或怪物阵营）行动开始；虚弱减层发生在**整轮结束**，粒度不同。

次数型（人工制品、缓冲）的层数 = 还能挡几次，既不是伤害强度也不是回合数。旗标型（路障）可以视为层数无意义，有就是有。

## 4. 生命周期：怎么加上、怎么叠、怎么掉

### 4.1 加上

「给某人上某种能力」是一次独立的、可被改写的行为，不是直接改数字：

- 可以被取消（人工制品对 Debuff）。
- 可以被改量（蛇颅骨：这次上毒 +1）。
- 成功之后可以再追加另一次施加（冠军腰带：成功上易伤后再上 1 虚弱）。
- **改量不是第二次施加**。蛇颅骨把 5 层毒变成 6 层，虐待倾向只触发一次；催化剂把毒翻倍，走的是一次新的施加，可以被人工制品拦住。

同名能力叠在同一条上，不并排两条「力量」。叠法按种类：

| 叠法 | 规则 | 例子 |
| --- | --- | --- |
| 加层 | 新层数加到旧层数上 | 再上 2 力量；再上 2 易伤 |
| 负层 | 允许层数为负 | 缴械 -2 力量，攻击伤害 -2 |
| 有无 | 再上一次通常无额外效果，或另有说明 | 路障 |
| 次数相加 | 可叠加次数 | 人工制品 1 + 1 = 还能挡 2 次 |

失败的施加（被人工制品取消）= 层数不变，也不触发「成功施加之后」的追加。

### 4.2 强度型怎么掉

默认本场战斗不按回合自然消失。掉层必须有明确原因：

- 结算时自减：中毒在行动开始造成等于当前层数的生命损失，然后 -1；到 0 不再结算。
- 配对能力吃掉：活动肌肉给力量的同时挂「力量下降」，所有者行动结束时按下降层数扣力量，再移除下降。
- 受击掉层：镀层护甲在受到**未被格挡的攻击伤害并实际失去生命**时 -1 层（被格挡吃光不掉；钨条把 1 削成 0 也不掉，见 wiki.gg Tungsten Rod 的 Order 小节）。
- 卡牌/遗物直接减或清：缴械、橙色药丸（清全部 Debuff）等。

再生（Regen）是「回合结束回血 = 层数，然后 -1」，和中毒镜像，但时点在行动结束而不是开始。

### 4.3 回合型怎么掉（含刚施加保护）

> **减层时点：一轮结束（玩家阵营和怪物阵营都结束）时，虚弱 / 易伤 / 脆弱等统一 -1。不是各自行动结束时分别减。**

1 层的玩家体验（与原版一致）：

- 你在自己的回合给敌人 1 层易伤：本回合剩下的攻击享受加成；本轮结束后易伤掉光。所以 1 层易伤主要吃「这回合后续攻击」。Bash 给 2 层，是为了让**下一回合**的攻击也吃到。
- 敌人在它的回合给你 1 层虚弱：若本轮结束立刻减层，你会在自己出牌前就掉光。因此有**刚施加保护**：这层能力跳过第一次轮末减层，保证至少完整覆盖你的下一段行动。

> **原版规则：保护由施加者决定，不看所有者。** 源码里回合型 Power 的 `justApplied` 由构造参数 `isSourceMonster`（施加者是不是怪物）决定：怪物施加的带保护、跳过一次轮末减层；玩家施加的不带。它**不是**「所有者本轮是否已行动完」的通用判断，也不要理解成「谁本轮施加的都不减」。

玩家视角的直觉表述（1 人局里与原版等价，便于验收）：

- 你在自己的回合给敌人加上 → 本轮结束正常减层。
- 敌人在它的回合给你加上 → 本轮结束不减，下一次轮结束再减。

这两句在「敌人给自己上回合型能力」这一支就不等价了：所有者还在行动中，但施加者是怪物，原版**带**保护。本仓库以施加方为准，见 [`../开发计划/Ver 0.x/0.7/游戏设计.md`](../开发计划/Ver%200.x/0.7/游戏设计.md) 第 4 节；不要把玩家向表述推广成多人或自施 Debuff 的通用规则。

无实体、纠缠等「持续若干段行动」的能力，减层节奏与「保证覆盖完整行动段」同一套直觉，层数表示还能撑几次减层点。

### 4.4 次数型怎么掉

- 人工制品：下一次 Debuff 施加被取消，层数 -1；到 0 移除。
- 缓冲：下一次**即将失去生命**时改为失去 0，层数 -1。伤害被格挡吃光、没有进入「即将失去生命」，则不消耗缓冲。中毒这种生命损失会消耗缓冲。1 点未格挡被钨条削成 0 **不是**「没扣血」——缓冲在钨条之前，仍会掉一层。详见 [伤害格挡与生命损失.md](伤害格挡与生命损失.md) 第 6 节。

## 5. 「修改能力」必须拆成两类

原版**没有**「所有能力强度 +N%」这种通用规则。真实存在的只有：

| 类别 | 玩家看到的事 | 例子 | 不是什么 |
| --- | --- | --- | --- |
| 改公式常数 | 层数不变，效果幅度变了 | 纸鹤：虚弱从减 25% 变成减 40%；纸蛙：易伤从 +50% 变成 +75%；怪异蘑菇：自己受到的易伤从 +50% 变成 +25% | 不是给虚弱加层，也不是再乘一层独立伤害 |
| 改这一次施加 | 这次加上的层数被改、被取消、或额外再上一件 | 蛇颅骨、人工制品、冠军腰带 | 不是全局「上毒永远 +1」写进中毒公式 |

两个容易误判成通用倍率的卡牌/遗物：

- **催化剂**：把目标当前中毒翻倍或三倍。这是卡牌效果，走一次施加，可被人工制品拦截。
- **圣树皮**：只翻倍**药水**数值，与能力施加无关。

## 6. 按行为模式分类（需求分析用）

做一种新能力时，先对上下面某一行，再填「何时、对谁、改什么」。不要为每张新牌发明一种生命周期。

### 6.1 强度型数值修正（无触发）

层数参与公式，自己不排队做事。

| 能力 | 极性 | 规则 |
| --- | --- | --- |
| 力量 | Buff（负层仍占同一条） | 该生物造成的**攻击伤害** + 层数。不加成生命损失、不加成荆棘、不加治疗 |
| 敏捷 | Buff（可为负） | 该生物**打出卡牌直接获得格挡**时 + 层数，再与脆弱相乘。金属化、镀层护甲、遗物、药水、冰霜球的格挡**不吃**敏捷；已有格挡不重算 |
| 集中 | Buff | 只服务充能球；没有球的角色拿到集中也不应改攻击/格挡公式 |

### 6.2 回合型倍率

有就生效，层数只表示持续时间。

| 能力 | 极性 | 默认幅度 | 作用对象 |
| --- | --- | --- | --- |
| 虚弱 | Debuff | 造成的攻击伤害 ×0.75 | 攻击发起方 |
| 易伤 | Debuff | 受到的攻击伤害 ×1.5 | 受击方 |
| 脆弱 | Debuff | **打出卡牌**获得的格挡 ×0.75；能力 / 遗物 / 药水 / 充能球的格挡不受影响 | 获得格挡的那一方 |

遗物可以改这些**常数**（见第 5 节），不改层数语义。

### 6.3 到点结算并自减

| 能力 | 时点 | 做什么 | 伤害类型 |
| --- | --- | --- | --- |
| 中毒 | **怪物身上**：怪物阵营行动开始，每只先清格挡、再全体结算中毒，早于任何一只出手，不是每只怪物各自出手前。**玩家身上**：玩家行动开始，能量重置之后 | 造成等于当前层数的生命损失，然后层数 -1 | 生命损失：不格挡、不受力/虚弱/易伤 |
| 再生 | 该生物自己的行动结束 | 回复等于层数的生命，然后 -1 | 治疗，不超过最大生命 |

中毒致死必须立刻判定胜负：怪物阵营开始时毒死最后一名敌人，则敌人不再出手。

### 6.4 到点结算但不按中毒方式自减

| 能力 | 时点 | 做什么 |
| --- | --- | --- |
| 金属化 | 该生物**自己的**行动结束（玩家侧在遗物之后、燃烧牌之前） | 获得等于层数的格挡，**不吃敏捷 / 脆弱** |
| 镀层护甲 | 同上获得格挡（同样不吃敏捷 / 脆弱）；受到未格挡攻击伤害并实际扣血时层数 -1 | 与金属化同时存在则各自结算 |
| 恶魔形态 | 所有者行动开始（能量重置之后） | 获得 2 层力量（强度型，常驻） |
| 仪式 | 所有者行动结束 | 获得等于层数的力量；邪教徒第一回合获得仪式时已过结束点，第二回合末才第一次加力量 |
| 路障 | 无触发 | 旗标：所有者行动开始**不清**格挡 |
| 模糊 | 持续到下一次自己的行动开始附近 | 下一次本该清格挡时不清（比路障短） |

金属化挂**行动结束**、中毒挂**行动开始**，两者不能共用一个时点。多怪物时怪物侧的金属化是逐只出手后结算还是全体出手后一起结算，见 [回合时序与能量.md](回合时序与能量.md) 2.6——玩家观察不出差别，写死一种即可。

### 6.5 拦截与改写即将发生的事

| 能力 | 拦截什么 | 不拦截什么 |
| --- | --- | --- |
| 人工制品 | 下一次 Debuff 施加整次取消 | Buff 施加；已经存在的 Debuff |
| 缓冲 | 下一次即将减少当前生命（缓冲在钨条之前） | 被格挡吃光的攻击（不到「即将失去生命」这一步） |
| 无实体 | 格挡**之前**把即将受到的伤害改为 1（攻击伤害、生命损失、**荆棘**都改） | 不把「扣血」改成 1——否则 50 打 10 格挡会错误地扣 1 血。正确：50 先变成 1，再被格挡吃掉，扣 0 血 |
| 纠缠 | 本段行动不能打出攻击牌 | 技能、能力牌、药水 |

### 6.6 受击时反应

| 能力 | 何时 | 做什么 |
| --- | --- | --- |
| 荆棘 | 被**攻击**打到（多段则每跳各算一次） | 对攻击方造成等于层数的荆棘伤害（被格挡，不受力/虚弱/易伤） |
| 火焰屏障 | 本回合被攻击打到 | 类似荆棘；通常伴随一次性格挡，持续到本回合结束 |
| 可塑 | 受到攻击伤害 | 获得递增的格挡 |

「被攻击打到」看的是攻击伤害这条路径，不是中毒。多段攻击每跳都触发荆棘，这是刻意的。算完 >0 但被格挡吃光，仍算被攻击；公式结果就是 0 的，不要按全格挡那条默认触发，见 [伤害格挡与生命损失.md](伤害格挡与生命损失.md) 第 2 节。

### 6.7 出牌或消耗时反应

| 能力 | 何时 | 做什么 |
| --- | --- | --- |
| 腐蚀 | 打出技能时 | 技能费用视为 0，且打出后消耗 |
| 回声形态 | 本段行动打出的前 N 张牌 | 再结算一次（复制的是这张牌的运行中实例，不是配置原型） |
| 双发 / 爆发 / 增幅 | 下 N 张攻击 / 技能 / 能力牌 | 再结算一次，次数用完移除 |
| 暗之拥抱 | 有牌被消耗 | 抽 1 |
| 无惧疼痛 | 有牌被消耗 | 获得格挡 |
| 千割 | 打出牌 | 对所有敌人造成固定伤害 |

「打出一张牌」是这些能力的共同钩子。强制结束回合、天鹅绒项圈「每回合最多打 6 张」数的也是这个钩子，不是点结束回合。

### 6.8 配对的临时能力（活动肌肉模式）

活动肌肉：**立刻**加力量，并挂上同等层数的「力量下降」。下降是 Debuff，在所有者行动结束时把力量减回去。

需求：

- 两步都是施加。下降可被人工制品拦住，拦住则力量加了但不会掉——这是原版允许的交互。
- 不能做成「到点把力量清空」，否则会吃掉同一回合从别处获得的力量。
- 偏执（Biased Cognition）、怨灵体（Wraith Form）同类：先给强力 Buff，再挂每回合惩罚。

### 6.9 改变流程旗标

这些能力不改伤害公式，只让某一步跳过或改写：

| 能力 | 改哪一步 |
| --- | --- |
| 路障 | 行动开始不清格挡 |
| 混乱（蛇眼） | 抽到的牌，费用变成 0～3 的随机值（改运行中费用，不改牌面印刷费用） |
| 不能抽牌 | 本段行动抽牌效果无效 |
| 时间扭曲（时间吞噬者） | 玩家累计打出 12 张牌后，强制结束玩家行动（见 [回合时序与能量.md](回合时序与能量.md)） |

「清格挡 / 重置能量」在原版里是默认可发生的流程步骤，能力或遗物可以让它**不发生**。需求上它们是开关，不是另一套能力生命周期。

## 7. 能力与伤害、格挡的关系（摘要）

完整管线见 [伤害格挡与生命损失.md](伤害格挡与生命损失.md)。能力侧只记谁参与哪一段：

```text
攻击伤害：力量、虚弱、易伤 →（无实体把伤害改为 1，荆棘同样经过这一步）→ 格挡 → 缓冲 → 钨条 → 扣血
打出卡牌获得格挡：敏捷、脆弱
能力 / 遗物 / 药水 / 充能球获得格挡：原样加，敏捷、脆弱都不参与
生命损失：力量/虚弱/易伤/格挡都不参与；无实体仍在格挡前把数值改为 1；缓冲在钨条之前把一次即将失去生命变成 0
荆棘：不参与攻击公式，经过无实体，被格挡，不触发对方荆棘
```

## 8. 展示与可读性需求

- 层数为 0 的能力应从列表消失（刚减到 0 的那次结算仍按减之前的层数执行，例如最后 1 层中毒仍打 1）。
- 负层力量必须能看出来（攻击预览要变低）。
- 敌人能力与玩家能力同一套规则，UI 都要能读。
- 意图伤害预览必须吃敌人自己的力量/虚弱和玩家的易伤，否则玩家无法做决策。

## 9. 明确不是能力的东西

| 东西 | 为什么不是能力 |
| --- | --- |
| 纸鹤、钨条、蛇颅骨等常驻遗物 | 待在遗物栏，不进任何生物的能力列表 |
| 卡牌关键词（消耗、虚无、固有、保留） | 是那张牌的属性，见 [卡牌类型与关键词.md](卡牌类型与关键词.md) |
| 手牌里的燃烧 | 牌在手牌区于阵营行动结束时结算，不是挂在生物上的中毒 |
| 药水效果本身 | 喝下去可能**施加**一个能力，药水槽里那瓶还不是能力 |

## 10. 对本项目的需求分析结论

不必实现本节出现的全部能力。但只要做其中一种，就必须满足该模式的时点、极性、层数语义和可拦截施加。最低限度的能力集合若要覆盖原版所有「模式」，而不是覆盖所有「内容」，对应关系是：

| 想证明的模式 | 原版最小例子 |
| --- | --- |
| 强度型被公式读取 | 力量 |
| 到点生命损失 | 中毒 |
| 回合型倍率 + 轮结束减层 + 刚施加保护 | 虚弱或易伤 |
| 角色行动结束获得格挡（且不吃敏捷 / 脆弱） | 金属化 |
| Debuff 施加可取消 | 人工制品 |
| 负层 | 缴械 |
