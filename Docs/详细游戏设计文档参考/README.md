## 统一术语

全文只用下表里的名字。原版把持续状态叫 Power，这里按玩家习惯拆成 Buff / Debuff，二者合称**能力**。

| 术语 | 含义 |
| --- | --- |
| 能力 | 挂在某个生物身上的持续状态（力量、中毒、易伤、路障……） |
| Buff / Debuff | 能力的极性。人工制品只拦 Debuff；中毒是 Debuff |
| 层数 | 能力上的那个整数。强度型 = 效果有多强；回合型 = 还剩几回合 |
| 刚施加保护 | 回合型能力跳过第一次轮末减层，避免「加上立刻过期」。原版按**施加者是不是怪物**打标（`isSourceMonster`）；「所有者已行动完才加上」只是它在 1 人局里的玩家视角解释，见 [Buff与Debuff.md](Buff与Debuff.md) 第 4.3 节 |
| 遗物 | 挂在玩家局外栏、进战斗仍生效的道具。多数**不会**变成生物身上的能力 |
| 药水 | 独立槽位里的一次性（或自动）道具，默认不耗能量、不计「打出一张牌」 |
| 一轮 | 玩家阵营行动一次 + 怪物阵营行动一次 |
| 阵营行动 / 角色行动 | 一方整体 vs 该方某个生物自己。玩家通常只有一人，这两级重合 |
| 攻击伤害 | 卡牌攻击、怪物攻击意图：受力、虚弱、易伤，被格挡 |
| 生命损失 | 中毒、部分自损：不受力/虚弱/易伤，不被格挡 |
| 荆棘伤害 | 反伤：不受力/虚弱/易伤，**被**格挡 |
| 抽牌堆 / 手牌 / 弃牌堆 / 消耗堆 | 原版仅此四区，没有判定区 |

## 写需求时三条总原则

1. **内容可以少，规则不能含糊。** 不必做出原版全部能力/遗物/药水；但每做一个，交互必须与本文该条一致（例如「纸鹤改的是虚弱倍率，不是再乘一层伤害」）。
2. **「改能力」有两种，不许混成一条通用倍率。** 改公式常数（纸鹤）和改这一次施加（蛇颅骨、人工制品）是两种需求，见 [Buff与Debuff.md](Buff与Debuff.md) 第 5 节与 [遗物.md](遗物.md) 第 3 节。
3. **时序要先对，粒度不必多。** 原版只有「回合开始 / 回合结束 / 轮结束」三档钩子，多怪物的差别是「怪物先全体做回合开始（清格挡、中毒），再逐只出手」这一条批处理规则；能量重置早于回合开始效果、清格挡早于毒发这类**顺序**才是会算错的地方。不要为此做成六个回调名。见 [回合时序与能量.md](回合时序与能量.md)。
