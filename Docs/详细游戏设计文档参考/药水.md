# 药水

> **一句话：药水是独立于牌组的消耗品，默认在自己的回合随时喝、不耗能量、不计入「打出一张牌」。它不是卡牌，也不是遗物；喝下去的结果往往是一次普通效果或一次能力施加，之后遵循那些效果自己的规则。**

## 1. 槽位与持有

| 规则 | 原版默认 |
| --- | --- |
| 槽位数 | 3；药水腰带改为 5 |
| 空槽 | 可见，战斗内外都能看 |
| 重复 | 允许持有两瓶相同药水 |
| 丢弃 | 玩家可以扔掉一瓶腾槽（通常在获得第四瓶时选择） |
| 战斗内获得 | 炼金、某些敌人掉落、熵能酿造等可以当场灌槽 |

槽位是局外状态，带着进每一场战斗。战斗里喝掉就空一格，战斗结束不会自动补（白兽雕像等遗物是战后额外掉落，不是回填已喝掉的瓶）。

## 2. 什么时候能喝

默认允许：玩家回合、战斗未结束、该槽有药水、没有「禁止使用药水」。

默认**不**消耗：

- 能量
- 「本回合打出张数」（天鹅绒项圈、时间吞噬者数的是打出的牌）
- 手牌位置

因此：0 能量、手里全是不能打的状态牌时，药水常常是唯一能做的事。这是药水存在的核心体验，不能改成「当一张 0 费技能」。

不能喝的情况：

| 限制 | 说明 |
| --- | --- |
| 添水杓（Sozu） | 整局不能使用药水；槽里的药还在，只是用不出 |
| 非玩家行动段 | 敌人行动中不能喝 |
| 战斗外 | 大多数药水只能在战斗里喝；见第 5 节例外 |
| 目标不合法 | 需要敌人的药水在没有存活敌人时不能用 |

喝出的效果若包含施加 Debuff，仍然走完整施加规则（人工制品、蛇颅骨、冠军腰带都适用）。药水不是「绕过能力系统的第二条通道」。

## 3. 和圣树皮、玩具啄木鸟的关系

| 遗物 | 对药水做什么 |
| --- | --- |
| 圣树皮 | **只**把药水的效果数值翻倍（伤害、层数、抽牌数、回复量等按该瓶的描述加倍）。不是「所有能力施加 ×2」，也不是改虚弱公式 |
| 玩具啄木鸟 | 每使用一瓶药水，回复少量生命 |
| 白兽雕像 | 战斗奖励多一瓶，不改使用规则 |

圣树皮的翻倍发生在「这瓶药结算数值」时。一瓶力量药水从 +2 力量变成 +4 力量，仍然是一次施加。人工制品若挡住这次施加，翻倍过的 Debuff 药水整瓶浪费（例如虚弱药水被挡住），这是允许的交互。

## 4. 按效果模式分类

不必实现全图鉴；新药水应对上其中一行。

### 4.1 即时战斗数值

不留能力，喝完就结束。

| 模式 | 原版例子 | 规则要点 |
| --- | --- | --- |
| 伤害 | 火焰药水（单体）、爆炸药水（全体） | 不要默认「药水 = 打出一张打击」。实现该瓶前按 wiki 核伤害类型；原版多数伤害药水更接近荆棘伤害：被格挡，不受力 / 虚弱 / 易伤 |
| 格挡 | 格挡药水 | 走获得格挡，吃敏捷和脆弱 |
| 抽牌 | 迅捷药水 | 受手牌上限约束，满手则抽不进手（见 [牌堆流转与打出.md](牌堆流转与打出.md)） |
| 能量 | 能量药水 | 本回合能量 +N，受冰淇淋影响（未用完可保留） |
| 回血 | 鲜血药水（按最大生命百分比） | 不超过最大生命 |

### 4.2 施加能力

| 模式 | 原版例子 | 规则要点 |
| --- | --- | --- |
| 给自己强度型 | 力量药水、敏捷药水、焦点药水 | 普通施加 Buff |
| 给自己次数型 | 古代药水（人工制品 1）、缓冲药水 | 普通施加 |
| 给敌人 Debuff | 虚弱 / 恐惧（易伤）/ 毒药药水 | 可被人工制品拦截；蛇颅骨对毒药水的施加 +1 |
| 给自己回合型 | 幽灵药水（1 层无实体） | 减层与刚施加保护按能力规则 |
| 仅本回合的强度 | 类固醇（本回合力量，结束时掉） | 活动肌肉那套配对能力，不是改力量公式 |

### 4.3 生成或改写卡牌

| 模式 | 原版例子 | 规则要点 |
| --- | --- | --- |
| 随机一张某类型进手 | 攻击 / 技能 / 能力 / 无色药水 | 生成的是运行中的牌；满手进弃牌堆 |
| 升级手牌 | 锻造祝福 | 改手牌里已有牌的升级状态 |
| 从弃牌堆取回 | 液态记忆 | 选弃牌堆中的牌上手，常伴随本回合费用变为 0 |
| 打出抽牌堆顶 | 蒸馏混沌 | 「打出」要走完整打出流程（可触发钢笔尖等），不是只结算伤害 |
| 复制下一张 | 复制药水 | 下一张打出的牌再结算一次 |

### 4.4 自动触发，不能主动喝

**仙灵药水**：生命本会降到 0 时改为回复到最大生命的一定比例，然后这瓶药消失。

- 挂钩点与蜥蜴尾巴相同：当前生命已经 ≤0、死亡判定前（以 [伤害格挡与生命损失.md](伤害格挡与生命损失.md) 第 7 节为准）。
- 玩家不能手动喝掉它来回血。
- 与蜥蜴尾巴同时存在时，需要一条固定优先级（原版仙灵优先于尾巴）。本项目若两件都做，必须写死顺序，不能「谁先注册谁先」。
- 圣树皮提高仙灵回复比例。

### 4.5 脱离战斗

**果汁**：最大生命 +5（圣树皮则 +10）。可在战斗外喝。

鲜血药水通常战斗内外都能喝。大多数伤害/Debuff 药水战斗外无目标，不能用。

**烟雾弹**：立刻结束本场非 Boss 战斗并视为逃离。Boss / 某些精英战不能用。这是流程级效果，不是伤害。

### 4.6 灌满槽位

**熵能酿造**：把所有空槽随机填满。不「喝掉自己再填」，就是生成药水进槽。

## 5. 战斗外使用清单（需求开关）

每瓶药需要一个标记：允许在什么场景使用。

| 场景 | 默认可喝的类型 |
| --- | --- |
| 玩家回合战斗内 | 几乎全部主动药 |
| 敌人回合 | 无 |
| 地图 / 休息处 / 商店 | 仅标记为「战斗外可用」的（果汁、部分回血） |
| 持有添水杓 | 主动喝与仙灵自动触发全部关闭。原版「不能使用药水」包含仙灵，不能靠它救命 |

上表按原版写死，不留给实现时猜测。

## 6. 和卡牌、遗物的分工

| 问题 | 答案 |
| --- | --- |
| 药水是不是 0 费技能？ | 不是。不占手牌、不进消耗堆、不触发「打出牌」计数（项圈、时间吞噬者、钢笔尖） |
| 喝药造出的牌再打出呢？ | 那张牌打出时正常计数 |
| 药水施加的力量和卡牌施加的力量有区别吗？ | 没有。进同一条力量 |
| 圣树皮会让催化剂翻倍吗？ | 不会。催化剂不是药水 |

## 7. 对本项目的需求分析结论

药水系统的最小闭环：

- 固定槽位、战斗内玩家回合使用、不耗能量
- 至少一瓶「即时数值」和一瓶「施加能力」，证明喝药走同一套伤害/施加规则
- 明确「打出牌」钩子不包含喝药

仙灵、烟雾弹、战斗外果汁、圣树皮都是可选内容；一旦做了，分别挂钩致死改写、强制结束战斗、局外可用标记、药水数值翻倍，不要把它们做成特殊卡牌。
