# 卡牌类型与关键词

> **一句话：类型决定这张牌「是什么」（攻击/技能/能力/状态/诅咒），关键词决定「打出后去哪、会不会自己消失、能不能被打出」。费用、目标、升级是每张牌的运行时属性，必须和配置上的印刷值分开记。**

## 1. 五种类型

| 类型 | 玩家含义 | 打出后默认去向 | 典型内容 |
| --- | --- | --- | --- |
| 攻击 | 对敌人造成攻击伤害的牌 | 弃牌堆（有消耗则进消耗堆） | 打击、痛击、双持 |
| 技能 | 格挡、抽牌、施加能力、改牌堆等非攻击主效果 | 同上 | 防御、毒液、上膛 |
| 能力牌 | 打出后给自己挂一条持续能力，本场留下效果 | **进消耗堆**（这是类型默认行为，不必每张都写消耗关键词） | 燃烧、恶魔形态、无实体、路障 |
| 状态 | 战斗中塞进牌组的「杂质」，多数不能打 | 不能打的留在手里直到被弃/虚无消耗；能打的（黏液）打出后通常消耗 | 伤口、晕眩、燃烧、黏液、虚空 |
| 诅咒 | 局外就进牌组的持久杂质 | 多数不能打；少数能打且有恶果 | 受伤、怀疑、正常、寄生、死灵诅咒 |

类型会被遗物和能力读取：「每打出 3 张**技能**」「打出**攻击**时」。因此类型是规则数据，不是描述性标签。治疗牌在原版里是技能，不是单独第六类。

无色牌、角色色（铁甲战士/静默猎手/缺陷/观者）是**颜色**，不是类型。无色可以是攻击或技能或能力牌。

## 2. 关键词（牌的属性，不是能力）

关键词写在牌上，跟着这张牌的实例走，不挂到生物身上。

| 关键词 | 规则 | 常见于 |
| --- | --- | --- |
| 消耗 | 打出后进入消耗堆，本场不再洗回抽牌堆 | 强力一次性、能力牌（类型已默认消耗） |
| 虚无 | 回合结束还在手里则**消耗**，而不是弃掉 | 晕眩、部分诅咒、部分强力牌 |
| 固有 | 第一回合抽起始手牌时，必须在手里（先把固有牌放进手再抽满） | 部分关键牌、瓶装遗物指定的那张 |
| 保留 | 回合结束不弃掉，留在手里 | 观者、部分防御 |
| 不能打出 | 永远不能被玩家打出 | 多数状态与诅咒 |
| 保留费用 / 费用变化 | 见第 4 节，不一定印成关键词 |

交互：

- **虚无 + 不能打出**：玩家这回合处理不掉，结束时被消耗。这是晕眩的意义。
- **消耗**只在「被打出」或「效果声明把这张牌消耗」时进消耗堆。弃掉一张带消耗的牌，是进弃牌堆，不是消耗。
- **保留**优先于普通弃牌；虚无在结束时仍会消耗（保留不能救虚无，除非效果明确改写）。
- 能力牌即使没印「消耗」两个字，打出后也进消耗堆。

燃烧是特殊状态牌：不能打出，**不虚无**；玩家阵营行动结束时若还在手里，对玩家造成 2（升级后 4）点伤害。这是「牌在手牌区结算」，不是生物身上的中毒能力。

原版把燃烧、悔恨、怀疑这类「结束时在手」的牌当作一次**由系统自动打出的牌走卡牌队列**结算——所以燃烧曾被误计入时间吞噬者的打出张数，Weekly Patch 51 才修掉。伤害类别按荆棘处理没问题（可被格挡、不受力 / 虚弱 / 易伤、不触发火焰屏障）；本项目若只把它做成一条荆棘伤害、不走「打出」路径，是有意简化，交互面比原版窄，需求里写明即可。

虚空：不能打出、虚无；**被抽到时**失去 1 点能量。钩子是「抽到」，不是「打出」。

## 3. 目标类型

原版玩家对多敌人时自由选目标，没有嘲讽。敌人只打玩家，不选目标。

| 目标 | 规则 |
| --- | --- |
| 单体敌人 | 必须有存活敌人；玩家指定一只 |
| 全部敌人 | 对当前所有存活敌人各结算一遍；结算中途有人死去则跳过死者 |
| 随机敌人 | 每一跳（或多段的每一段）在存活敌人里随机；必须用战斗种子，保证可复现 |
| 自身 | 不选目标 |
| 无目标 | 不选目标（部分全场效果、抽牌） |

没有合法目标则不能打出（例如场上没有敌人时的单体攻击）。全体牌在仍有至少一个敌人时可以打。

多段攻击：每一跳独立选目标（随机多段会跳来跳去）或锁定开打时那个目标（单体多段）。必须在牌的需求里写死，不能两种混用而不声明。

## 4. 费用

### 4.1 印刷费用与当前费用

配置上的费用是印刷值。打出检查的是这张牌**此刻的当前费用**。下列效果改当前费用，不改印刷值：

| 来源 | 行为 |
| --- | --- |
| 混乱 / 蛇眼 | 抽到时随机成 0～3 |
| 疯狂 | 本场某张牌费用变为 0 |
| 腐蚀 | 技能当前费用视为 0 |
| 建立（观者） | 保留的牌费用 -1 |
| 本回合减费 | 「下一张攻击费用为 0」等，用完或回合结束恢复 |

升级通常改印刷值（2 费变 1 费），那是另一份定义，不是运行时临时减费。

当前费用可以是 0。0 费牌仍是一次「打出」，计入项圈和时间吞噬者。

### 4.2 X 费

打出时花费**当前全部能量**，效果按花费的点数结算。0 能量也可以打，此时 X=0（牌仍被打出，可能什么都不做或仍有保底）。

遗物化学 X：X 额外 +2，即使你花了 0。需求上 X 的计算是「实际花费 + 固定修正」，不是「能量上限」。

### 4.3 能量不够

当前费用 > 当前能量 → 不能打出。没有「透支」。药水不走这条检查。

## 5. 升级

升级是牌组里那张牌的持久状态（本场生成的临时牌也可以被升级，只活在本场）。

常见升级方式（写需求时选一种写死）：

- 数值变大（伤害 6→9，格挡 5→8）
- 费用变少
- 加上关键词（获得消耗、获得固有）
- 额外效果（打击升级只加伤害；痛击升级加易伤层数）

同一张牌不能升两级。展示上名称带 `+`。

## 6. 状态牌与诅咒（作为机制，不是图鉴）

### 6.1 状态牌：本场杂质

战斗中由敌人、卡牌、遗物塞入。战斗结束全部消失，不带出牌组。

| 状态 | 能不能打 | 结束时 | 额外规则 |
| --- | --- | --- | --- |
| 伤口 | 否 | 普通弃掉 | 纯占手 |
| 晕眩 | 否 | 虚无，消耗 |  |
| 燃烧 | 否 | 若还在手，对玩家造成伤害再弃 | 按荆棘伤害处理：被格挡，不受力/虚弱/易伤，不触发对方荆棘 |
| 黏液 | 能，通常 1 费 | 打出后消耗 | 用来「交税」清手 |
| 虚空 | 否 | 虚无 | 抽到失 1 能量 |

### 6.2 诅咒：局外杂质

进玩家牌组，跨战斗存在。休息处、商店、事件才能拿掉（部分诅咒例外）。

| 模式 | 例子 | 规则要点 |
| --- | --- | --- |
| 纯占牌 | 受伤、笨拙（笨拙带虚无） | 稀释牌组 |
| 结束时惩罚 | 怀疑（得 1 虚弱）、羞耻（得 1 脆弱）、衰亡（受伤）、悔恨（按手牌数失血） | 在玩家阵营行动结束、弃牌前后的时点要写清：悔恨按**当时手牌数** |
| 打出时惩罚 | 痛苦（每打出一张牌失 1 生命） | 数的是打出，喝药不算 |
| 限制打出 | 正常（本回合最多打 3 张牌） | 与项圈同类，取更严的上限 |
| 不能被消耗 | 死灵诅咒 | 消耗后回到手牌或抽牌堆；「消耗掉诅咒」的策略对它无效 |
| 移除时惩罚 | 寄生 | 被移除或变化时失去最大生命 |

能力牌「燃烧」（Ironclad Power，英文 Inflame）和状态牌「燃烧」（Burn）中文同名时必须在文案里区分，需求里用「能力：燃烧 / 状态：燃烧牌」避免混。

## 7. 打出限制清单（前到后检查）

一张牌能被打出，需要同时满足：

1. 现在是玩家行动段，战斗未结束。
2. 不是「不能打出」。
3. 未被纠缠等能力禁止该类型。
4. 未达到本回合打出上限（正常、天鹅绒项圈、时间吞噬者在第 12 张时会先强制结束——若已经结束则打不出）。
5. 当前能量 ≥ 当前费用（X 费视为 0 即可打）。
6. 有合法目标。
7. 手牌里确实持有这张实例。

失败时牌不能离开手牌、不能扣费。

## 8. 复制、生成、变化

| 操作 | 需求 |
| --- | --- |
| 生成一张牌 | 生成运行中的实例（可带临时费用、临时升级），放进手/抽/弃之一；满手改放弃牌堆 |
| 复制打出 | 复制的是这次打出的实例（含当前费用、升级、力量快照按结算时再算），不是从配置重新 new 一张未升级牌 |
| 变化 | 从牌池按规则换成另一张，原实例离开牌组 |

回声形态、双发、复制药水都依赖「打出」这个事件和运行中实例。见 [牌堆流转与打出.md](牌堆流转与打出.md)。

## 9. 对本项目的需求分析结论

类型与关键词是卡牌机制的骨架，和「这张牌打 6 点」的数值无关：

- 至少要有攻击 / 技能二分，能力牌在出现「打出后常驻」时引入（默认进消耗堆）
- 消耗堆与消耗关键词是同一需求
- 状态牌是多敌人、污染牌组玩法的前提；诅咒是局外成长的惩罚
- 当前费用必须与印刷费用分离，否则蛇眼、腐蚀、本回合减费都做不成

充能球（缺陷）与姿态（观者）是角色子系统，不是第六种卡牌类型：它们改变能量与伤害倍率，但牌仍是攻击/技能/能力牌。本文件夹不单开文档；若做这两名角色，再写专项需求，不要把「引导一个闪电球」误做成一种新卡牌类型。
