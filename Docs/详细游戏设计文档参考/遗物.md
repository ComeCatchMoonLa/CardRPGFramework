# 遗物

> **一句话：遗物是玩家「人」上的常驻道具，进每场战斗都还在；它们复用和能力相同的钩子形状（到点做事，或改一次数值），但大多数不会变成生物能力列表里的一条。** 开战塞一层力量的金刚杵是例外中的典型——遗物只在开战那一下施加 Buff，之后战场上留下的是力量，不是金刚杵本身。

## 1. 和能力的边界（最容易写错的一条）

| | 能力 | 遗物 |
| --- | --- | --- |
| 挂在哪 | 某个生物本场的能力列表 | 玩家的遗物栏（局外就有，进战斗带着） |
| 战斗结束 | 全部清掉 | 还在，下一场继续 |
| 玩家怎么读 | 头像旁的图标 | 独立遗物栏 |
| 例子 | 力量、中毒、路障 | 纸鹤、钨条、蛇颅骨、咖啡滤杯 |

三种合法形态，不要混：

1. **开战注入型**：战斗开始时施加一个普通能力，然后这件遗物本场可以不再说话。例：金刚杵 → 1 力量；弹珠袋 → 所有敌人 1 易伤。
2. **整场常驻型**：从不进能力列表，计算或事件发生时直接问「有没有这件遗物」。例：纸鹤、钨条、蛇颅骨。
3. **计数器型**：遗物自己记一个数（第几张攻击、第几回合），到点触发。例：钢笔尖每 10 次攻击翻倍；快乐花每 3 个回合 +1 能量。

反例：把纸鹤做成「给玩家上一个叫纸鹤的 Buff」——能力列表会被污染，清 Buff 的效果会误删它，也会和「修改虚弱公式」的需求缠在一起。

## 2. 玩家规则（与内容量无关的部分）

- 同一件遗物默认不能持有两份（原版拾取时直接跳过重复）。分析需求时按「有或没有 + 计数器」即可，不要按层数叠两件纸鹤。
- 遗物效果在**所有战斗**生效，含开局教学战之后的每一场；部分遗物写明只在特定房间（如燃烧之血是战斗**结束**回血）。
- 玩家必须随时能看见自己有哪些遗物、计数器型还差几次。
- 遗物**不占手牌、不耗能量**，也不是打出一张牌。

稀有度（初始 / 普通 / 罕见 / 稀有 / Boss / 商店 / 事件）只影响获取，不改变上面四条。本文件按**钩子种类**分类，不按稀有度罗列全图鉴。

## 3. 钩子种类（做一件遗物时对号入座）

### 3.1 改公式常数（不动任何人的层数）

计算伤害或格挡时，读取「当前这场该用哪个倍率 / 哪个下限」。

| 遗物 | 改哪条常数 | 不改什么 |
| --- | --- | --- |
| 纸鹤 | 虚弱倍率 0.75 → 0.60（减伤 25%→40%） | 不给敌人加虚弱层数 |
| 纸蛙 | 易伤倍率 1.5 → 1.75 | 不加易伤层数 |
| 怪异蘑菇 | 自己受到的易伤倍率 1.5 → 1.25 | 敌人打别人仍用默认易伤 |
| 腕刃 | 费用为 0 的攻击牌伤害 +4 | 不改费用本身 |

需求：公式必须能读到「本场持有的遗物」，不能只读交战双方能力列表。否则纸鹤无法生效。

### 3.2 改这一次施加（不是改公式）

发生在「给某人上能力」这次行为上，可改量、可取消、可追加。

| 遗物 | 行为 | 关键边界 |
| --- | --- | --- |
| 蛇颅骨 | 你施加中毒时，这一次层数 +1 | 不是第二次施加；虐待倾向不因此多触发一次 |
| 冠军腰带 | 你成功施加易伤后，再施加 1 虚弱 | 这是另一次施加；若易伤被人工制品挡住，则不追加虚弱 |
| （能力）人工制品 | 取消下一次 Debuff 施加 | 与遗物同形状的钩子，挂在生物身上 |

施加必须带「谁在施加」。腰带、蛇颅骨都只响应**玩家作为施加者**的那一次。

### 3.3 伤害管线上的不同挂钩点

三件遗物/能力看起来都像「少挨打」，挂钩点完全不同。挂错会出反例：50 攻击、10 格挡、无实体 → 正确是先变成 1 再被格挡吃掉，掉 0 血。

```text
攻击公式（力量 / 虚弱 / 易伤）          ← 仅攻击伤害
    ↓
格挡前最终修正（无实体：改为 1）        ← 凡是还没进格挡的伤害数字都经过（攻击、生命损失、荆棘）
    ↓
格挡吸收                                 ← 攻击与荆棘；生命损失跳过
    ↓
格挡后观察（鸟居：未被格挡的攻击伤害 ≤5 → 1）  ← 仅攻击伤害
    ↓
缓冲（值 >0 则改为 0 并减 1 层）
    ↓
钨条（这次扣血 -1，至少 0）              ← 不看来源，中毒也减
    ↓
当前生命减少
```

| 名称 | 种类 | 挂钩点 | 范围 |
| --- | --- | --- | --- |
| 无实体 | 能力 | 格挡前改为 1 | 攻击伤害、生命损失、荆棘 |
| 鸟居 | 遗物 | 格挡后、未被格挡的攻击伤害 ≤5 则改为 1 | 仅攻击伤害 |
| 缓冲 | 能力 | 格挡与鸟居之后、钨条之前：值 >0 则改为 0 并减层 | 所有即将扣血 |
| 钨条 | 遗物 | 缓冲之后、即将减少当前生命时 -1 | 所有真正扣血，含中毒 |
| 靴子 | 遗物 | 你造成的未被格挡攻击伤害若 ≤4，改为 5 | 你打出去的攻击，不是挨打 |

原版顺序是 **格挡 → 鸟居 → 缓冲 → 钨条**（与 [伤害格挡与生命损失.md](伤害格挡与生命损失.md) 的 ⑤→⑥ 一致）。1 点未格挡伤害时：缓冲先看到 1 并消耗一层，再轮到钨条（此时已是 0）。不要做成「钨条先把 1 削成 0，缓冲因此不掉」——那和原版相反。

「伤害被格挡吃光则不消耗缓冲」仍然成立，那是④之后值为 0、根本不问缓冲。不要把它和「钨条把 1 削成 0」混成一句。

### 3.4 开战时一次性

战斗开始、洗牌之后、第一段玩家行动之前：

| 遗物 | 效果 |
| --- | --- |
| 金刚杵 | 获得 1 力量 |
| 锚 | 第一回合获得格挡（只挡第一段敌人行动前的空窗） |
| 弹珠袋 | 所有敌人获得 1 易伤 |
| 准备背包 | 第一回合多抽 2 张 |
| 裂核 / 纯净水 | 开局一个球 / 一张奇迹，属于角色子系统 |

这类遗物的需求是「战斗开始」这个时点必须存在，并且此时敌人已经生成、牌堆已经建好。

### 3.5 改回合资源规则（开关，不是公式）

| 遗物 | 改哪一步默认流程 |
| --- | --- |
| 冰淇淋 | 行动开始**不把能量清成上限**，未用完的能量留到下回合 |
| 符文金字塔 | 行动结束**不弃手牌**（手牌上限仍在，满 10 张会卡住抽牌） |
| 快乐花 | 每 3 个自己的回合开始额外 +1 能量（计数器） |
| 焚香炉 | 每 6 个回合获得 1 层无实体 |

默认流程是：行动开始清格挡、能量重置为上限、抽 5；行动结束弃光手牌。遗物/能力可以关掉其中一步。需求上检查「本场是否允许清格挡 / 是否允许重置能量 / 是否弃手」即可，不必为这三件事各做一套能力。

路障是能力版「不清格挡」，和冰淇淋同一种需求模式、不同挂载位置。

### 3.6 计数器：每 N 次

必须定义清楚数什么、何时清零、跨战斗是否保留。

| 遗物 | 数什么 | 跨战斗 |
| --- | --- | --- |
| 钢笔尖 | 打出的攻击牌次数，第 10 次该次攻击伤害翻倍 | 通常保留进度 |
| 双节棍 | 同上，每 10 次获得 1 能量 | 保留 |
| 开信刀 | 每打出 3 张技能，对所有敌人造成固定伤害 | 保留 |
| 日晷 | 每洗牌 3 次获得能量 | 保留 |

「打出攻击牌」和「造成一次攻击伤害」不是一回事：多段攻击牌对钢笔尖通常计 **1 次打出**，但翻倍覆盖这一次打出的每一跳。需求必须写清计数单位是「打出」还是「伤害跳数」。

### 3.7 打出 / 抽到 / 洗牌 / 消耗时

与能力第 6.7 节同一类钩子，只是监听者在遗物栏：

- 抽到牌：墨水瓶（每回合第一张抽到的牌耗 0）、蛇眼（见 Boss 契约：抽到即随机费用）
- 消耗：死灵之书、干尸花（消耗时触发）
- 洗牌：日晷、冰冷之蛋（抽到能力牌则升级）等「蛋」系列

### 3.8 一次性救命

| 遗物 | 规则 |
| --- | --- |
| 蜥蜴尾巴 | 当前生命已经 ≤0 时、死亡判定前，改为 50% 生命，然后这件遗物耗尽（变灰、本局不再触发） |
| 精致尾羽等 | 同类「触发一次后耗尽」 |

时点以 [伤害格挡与生命损失.md](伤害格挡与生命损失.md) 第 7 节为准：先完成扣血（生命可以到 0），再问致死改写，最后才死亡。耗尽状态必须可见。仙灵药水不是遗物，但是同一挂钩点（见 [药水.md](药水.md)）。

### 3.9 Boss 能量契约

+1 能量（或等价强力）换一条硬限制。限制是流程开关或额外规则，不是 Buff。

| 遗物 | 得到 | 付出 |
| --- | --- | --- |
| 咖啡滤杯 | 每回合能量上限 +1 | 不能休息回血 |
| 熔接锤 | 上限 +1 | 不能锻造升级 |
| 天鹅绒项圈 | 上限 +1 | 每回合最多打出 6 张牌，第 7 张打不出 |
| 添水杓（Sozu） | 上限 +1 | 不能使用药水 |
| 灵体 | 上限 +1 | 不再获得金币 |
| 哲人石 | 上限 +1 | 所有敌人开战 +1 力量 |
| 符文圆顶 | 上限 +1 | 看不见敌人意图 |
| 诅咒钥匙 | 上限 +1 | 宝箱带诅咒 |
| 破碎王冠 | 上限 +1 | 卡牌奖励少 1 选 |
| 蛇眼 | 每回合多抽 2 | 抽到的牌费用随机 0～3 |
| 符文金字塔 | 不弃手 | 没有 +1 能量 |
| 痛苦印记 | 上限 +1 | 开战手牌塞入 2 张伤口 |

项圈与时间吞噬者都需要「本回合已打出张数」这条数据；限制的是打出，不是喝药水。

### 3.10 局外遗物（本文件夹不展开地图，只记接口）

燃烧之血、黑星、送货员、白兽雕像、药水腰带、圣树皮等在战斗外或战斗结束时生效。局内需求只要求：战斗结束能通知遗物、药水槽数量能被腰带改写、圣树皮能被药水读取。地图、商店、篝火规则不在本文件夹展开。

## 4. 遗物不是通用 Buff 修改器

不要做「任意能力强度 +N%」来实现纸鹤。原版没有这种东西。对照：

| 错误抽象 | 原版实际 |
| --- | --- |
| 遗物 = 永不消失的 Buff | 只有开战注入型长得像；常驻型根本不进能力列表 |
| 遗物 = 第三条能力生命周期 | 钩子形状相同，容器不同 |
| 所有「改 Debuff」都是倍率 | 改常数 vs 改这一次施加，见第 3.1 / 3.2 节 |

## 5. 对本项目的需求分析结论

第一件遗物出现时，必须已经有：

- 本场可见的遗物列表（与能力列表并列）
- 战斗开始 / 行动开始 / 打出牌 / 即将失去生命 / 施加能力 这些时点能问到遗物
- 伤害公式能读遗物改过的常数
- 默认流程步骤（清格挡、重置能量、弃手）可被跳过

不需要先做齐 Boss 契约和全图鉴。按模式验收时，每类各一件即可证明需求：金刚杵（注入）、纸鹤（改常数）、钨条（扣血前）、蛇颅骨（改施加）、冰淇淋（流程开关）、钢笔尖（计数器）。
