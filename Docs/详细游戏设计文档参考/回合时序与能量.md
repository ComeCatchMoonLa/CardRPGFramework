# 回合时序与能量

> **一句话：一轮 = 玩家阵营行动一次 + 怪物阵营行动一次。怪物阵营先对全体怪物做「清格挡 → 中毒」，再逐只出手。玩家行动开始的顺序是清格挡 → 能量重置 → 抽牌 → 回合开始效果。能量默认每段玩家行动开始重置为上限，不累积；冰淇淋把「= 上限」换成「+= 上限」。**

「回合」一词在玩家口语里有时指自己出牌那一段，有时指一整轮。本文用**一轮 / 阵营行动 / 角色行动**三层，避免混用。

## 1. 时点模型（观测分层，不是引擎 API）

```text
回合行动开始
  玩家阵营行动开始
    玩家角色行动开始 → 玩家出牌 → 玩家角色行动结束
  玩家阵营行动结束
  怪物阵营行动开始
    怪物 A 角色行动 → 怪物 B 角色行动 → …
  怪物阵营行动结束
回合行动结束（一轮结束）
```

这套分层来自 bakabird 的观测笔记，用来解释「所有怪物一起毒发」「这只怪物自己出手后获得金属化格挡」「减层在轮末」三件事是够的。但原版引擎只有「回合开始 / 回合结束 / 轮结束」三档钩子，多怪物的差别是**先对全体怪物跑完回合开始（清格挡、中毒），再逐只出手**这一条批处理规则。玩家通常只有一个生物，「玩家阵营开始」和「玩家角色开始」是同一时刻。写需求时用这三层描述时点没问题，但不要把它做成六个回调名。

## 2. 一场战斗从开始到一轮里发生的事

### 2.1 战斗开始（第一轮之前）

1. 用本场牌组构建抽牌堆并洗牌（固有牌按规则抽出，见 [牌堆流转与打出.md](牌堆流转与打出.md)）。
2. 抽起手牌（默认 5 张）。这就是第一段玩家行动的抽牌，2.2 第 3 步在第一回合不再重复。
3. 遗物的开战效果，**按拾取顺序**结算（金刚杵、弹珠袋、锚、准备背包多抽 2、痛楚印记洗入 2 张伤口……）。痛楚印记的伤口进的是**抽牌堆**，且在起手抽完之后，所以默认第一手抽不到；准备背包若在痛楚印记之后拾取，多抽的 2 张才可能抽到伤口。
4. 每个敌人展示**第一个**意图（实际在生成时就已决定）。
5. 进入第一段玩家阵营行动：能量重置、回合开始效果照常，抽牌已在第 2 步完成。

### 2.2 玩家阵营 / 角色行动开始

顺序固定，前一步的死亡判定通过后才做下一步：

| 顺序 | 事件 | 谁可以改 |
| ---: | --- | --- |
| 1 | 清除自己的格挡 | 路障、模糊 |
| 2 | 能量重置：当前能量 = 上限 | 冰淇淋：当前能量 += 上限 |
| 3 | 抽到本回合张数（默认 5；第一回合见 2.1） | 「不能抽牌」；符文金字塔不在此时，它改的是结束弃牌 |
| 4 | 回合开始效果（玩家身上的中毒、恶魔形态、残杀抽牌、狂暴 +1 能量、快乐花……） | — |
| 5 | 若玩家已死 → 失败 | 仙灵 / 蜥蜴尾巴可能在扣血时已改写 |

能量重置必须早于任何「回合开始获得能量」的效果——放反了，狂暴那 1 点会被「当前能量 = 上限」抹掉。wiki.gg Mechanics 给的玩家可见顺序就是「能量 → 抽牌 → 回合开始效果」；源码把回合开始钩子再分抽牌前 / 抽牌后两档，做具体能力时按该能力核对它在哪一档，两档都在能量重置之后。

中毒若在玩家身上，在第 4 步按当前层数造成生命损失再 -1 层。

### 2.3 玩家角色行动中

玩家可以按任意顺序：

- 打出合法的牌（每次打出是一次完整结算，见 [牌堆流转与打出.md](牌堆流转与打出.md)）
- 使用合法的药水（不耗能量、不计打出张数）
- 点击结束回合（主动结束本段行动）

系统也可以结束这段行动：

| 来源 | 规则 |
| --- | --- |
| 时间吞噬者的时间扭曲 | 本场玩家累计打出 12 张牌后，强制结束当前玩家行动。计数跨玩家的多段行动累计；第 12 张那一次结算会打完，但若它是双发 / 回声形态的第一遍，第二遍会成为第 13 张而**不会发生**（社区实测一致） |
| 天鹅绒项圈 | 本段行动已打出 6 张则不能再打，但可以喝药、可以点结束 |
| 诅咒「正常」 | 本段最多 3 张 |

「结束玩家行动」必须是规则能触发的命令，不能只存在于 UI 按钮。否则时间吞噬者无法实现。

任意一次结算后玩家生命 ≤0 且无致死改写 → 失败；敌人全灭 → 胜利，不再进入怪物阵营。致死改写时点见 [伤害格挡与生命损失.md](伤害格挡与生命损失.md) 第 7 节。

### 2.4 玩家角色行动结束 → 玩家阵营行动结束

| 顺序 | 事件 |
| ---: | --- |
| 1 | 遗物的结束触发（奥利哈钢等） |
| 2 | 角色行动结束触发（金属化获得格挡、活动肌肉的力量下降、再生回血……） |
| 3 | 仍在手里的牌做「结束时在手」结算（燃烧伤害、悔恨按**此时**手牌张数失血、怀疑等） |
| 4 | 虚无牌消耗 |
| 5 | 其余未保留手牌弃掉 |

「遗物 → 能力 → 牌」的顺序见 wiki.gg Mechanics（奥利哈钢先于镀层护甲先于燃烧）与 V2.0 补丁说明（*Powers that gain Block at end of turn activate before cards like Burn play themselves*）。本节只承认这一条顺序，不要再写成「先弃牌再结算手里的燃烧」。悔恨与燃烧同一时点、都在弃牌之前，按当时手牌数结算，不会和弃牌后的张数打架。

### 2.5 怪物阵营行动开始

**对每只怪物：先清除它的格挡（路障 / 模糊例外），再结算它的回合开始能力（中毒：生命损失，然后 -1 层）。全部怪物走完这一步，才有任何一只出手。**

两条后果都是原版实测：

- 全体毒发早于任何出手——三只毒蛙一起掉血，左边那只不会先打完再毒发（Reddit 多怪毒发讨论一致）。
- 毒发在清格挡**之后**——守护者被毒发切进防御形态时获得的 20 格挡已经过了清格挡点，会留到玩家回合（wiki.gg Poison）。旧版把清格挡写在每只出手前、毒发之后，会把这层格挡错误清掉。
- 毒死带随从的召唤者，随从仍会逃走（不再出手）。

若因此全部敌人死亡 → 胜利，不再执行任何怪物的角色行动。

### 2.6 每只怪物的角色行动

对每个仍存活的怪物，按站位从左到右（或固定编队顺序）：

| 顺序 | 事件 |
| ---: | --- |
| 1 | 若处于眩晕 / 意图已不可执行 → 跳过出手 |
| 2 | 执行当前意图（攻击走攻击伤害管线；施加能力走施加规则） |
| 3 | **立刻决定并展示下一轮意图** |

第 3 步是意图系统的核心：玩家在接下来整段自己的行动里都能看见敌人下一击。不是玩家回合开始才掷骰。

怪物的「行动结束」能力（金属化、仪式）在它出手之后、玩家回合开始之前结算。多怪物时是逐只出手后各自结算，还是全体出手完一起结算，公开资料没有写清，玩家在自己的回合里也观察不出差别——本项目做多怪物时二选一写死即可，不要为此发明第二套时点。

一只怪物在第 2 步里把玩家打死 → 失败，后续怪物不再行动。

### 2.7 一轮结束

虚弱 / 易伤 / 脆弱等回合型能力统一减 1 层，刚施加保护见 [Buff与Debuff.md](Buff与Debuff.md) 第 4.3 节。

然后进入下一轮的玩家阵营行动开始。没有「双方同时行动」。观者的金库（Vault）是唯一能跳过整个怪物阵营和这一步减层的效果，见第 5 节。

## 3. 能量

| 规则 | 默认 |
| --- | --- |
| 上限 | 3，可被 Boss 遗物 +1，可被卡牌本场提高 |
| 每段玩家行动开始 | 当前能量 = 上限（冰淇淋：当前能量 += 上限） |
| 未用完 | 丢弃（冰淇淋：留下，与下回合的上限相加） |
| 打出 | 当前能量 -= 该牌当前费用 |
| X 费 | 把当前能量全部花掉，X = 花掉的数；化学 X 在 X=0 时仍 +2 |
| 药水 | 不耗能量 |
| 获得能量效果 | 加在当前能量上，本段行动可用；可以超过上限 |

冰淇淋：把「当前能量 = 上限」换成「当前能量 += 上限」。上限 3、剩 2 → 下回合 **5**；剩 10 → **13**（wiki.gg Ice Cream 原文 *adds the maximum energy limit to the player's current energy*）。旧版写的「完全不重置、剩 2 就以 2 开始」是错的，按那样做会做出一件废遗物。

快乐花、狂暴等「回合开始 +N 能量」发生在重置之后，加在已经重置好的当前能量上；冰淇淋下这些额外能量同样可以留到下回合。

## 4. 抽牌张数与手牌上限的时序位置

默认每段玩家行动开始抽到 5 张（手牌已有保留牌则只抽差额，还是抽满到 5？）。原版是**抽 5 张**，不是「抽到手牌=5」。手里因符文金字塔留了 7 张，再抽 5 会撞手牌上限 10，多的抽不出来。

准备背包：第一回合额外抽 2，在 2.1 第 3 步的开战遗物阶段按拾取顺序结算（起手 5 张之后），不是常规抽牌数 +2。

## 5. 强制结束与「额外回合」

- 强制结束玩家行动 ≠ 跳过怪物行动。时间吞噬者让你停手后，仍进入怪物阵营。
- 某些敌人在血线以下会「获得额外一轮行动」（在同一轮结构里插入又一次怪物阵营，或立刻再执行一次角色行动）。需求上「角色行动」必须能被规则再次调度，不能写死「每轮每个敌人恰好一次」。
- 玩家侧「额外回合」在一代只有观者的金库（Vault）：结束本回合、**跳过整个怪物阵营和轮结束**（敌人格挡不清、虚弱 / 易伤 / 脆弱不减层、敌人的回合结束能力不触发），直接进入下一段玩家行动（清格挡、重置能量、抽牌、回合开始效果照常）。一代没有「双动遗物」；本项目若做额外回合，按金库写。

## 6. 时点粒度对照（验收用）

| 能力 / 规则 | 正确时点 | 挂错会怎样 |
| --- | --- | --- |
| 清格挡 | 玩家：自己行动开始。怪物：怪物阵营开始，每只各清，早于毒发和出手 | 挂到行动结束则防御牌挡不住敌人；怪物侧挂到毒发之后，守护者防御形态的格挡会被清掉 |
| 玩家中毒 | 玩家行动开始，能量重置之后（回合开始效果） | 挂到结束则玩家能先打完再毒发，节奏反了 |
| 怪物中毒 | 怪物**阵营**行动开始，全体一起，早于任何出手 | 挂到每只出手前，则左怪毒死时右怪可能已经出过手，或顺序依赖站位 |
| 金属化 | 该生物行动结束（玩家侧在遗物之后、燃烧之前） | 挂到行动开始或阵营开始，格挡会在错误的时间出现或被清掉 |
| 虚弱减层 | 一轮结束 | 挂到各自行动结束，1 层易伤无法覆盖「本回合后续出牌」的预期 |
| 能量重置 | 玩家行动开始、清格挡之后、回合开始效果之前 | 放到回合开始效果之后，狂暴 / 快乐花的 +1 会被「= 上限」抹掉 |
| 燃烧牌 | 玩家阵营结束、能力之后、弃牌之前 | 见 2.4 |

## 7. 对本项目的需求分析结论

- Phase 1 的「玩家回合 → 敌人打一下」是一代结构在 1v1 下的退化，不假；多怪物需要的是「怪物先全体做回合开始（清格挡、中毒）再逐只出手」这一条批处理规则和轮末减层，不是六级回调。
- 结束玩家行动是规则命令。
- 清格挡、弃手是两扇可被关掉的门；能量重置是一步可换算法（`=` 上限 → `+=` 上限）的操作，且必须早于回合开始效果。默认全开。
- 意图在敌人自己出手末尾刷新，保证玩家整段行动都能看见下一击。
