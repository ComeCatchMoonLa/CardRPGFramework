# 回合时序与能量

> **一句话：一轮 = 玩家阵营行动一次 + 怪物阵营行动一次。阵营内部再按每个生物的「角色行动」展开。不同能力挂在不同级的时点上：中毒挂阵营开始，金属化挂角色结束。能量默认每段玩家行动开始重置为上限，不累积。**

「回合」一词在玩家口语里有时指自己出牌那一段，有时指一整轮。本文用**一轮 / 阵营行动 / 角色行动**三层，避免混用。

## 1. 四级时序

```text
回合行动开始
  玩家阵营行动开始
    玩家角色行动开始 → 玩家出牌 → 玩家角色行动结束
  玩家阵营行动结束
  怪物阵营行动开始
    怪物 A 角色行动 → 怪物 B 角色行动 → …
  怪物阵营行动结束
回合行动结束（一轮结束）
```

玩家通常只有一个生物，所以「玩家阵营开始」和「玩家角色开始」是同一时刻。多怪物时，「所有怪物一起毒发」和「这只怪物自己行动结束获得金属化格挡」必须是两个时点。

## 2. 一场战斗从开始到一轮里发生的事

### 2.1 战斗开始（第一轮之前）

1. 用本场牌组构建抽牌堆并洗牌（固有牌按规则抽出，见 [牌堆流转与打出.md](牌堆流转与打出.md)）。
2. 遗物的开战效果（金刚杵、弹珠袋、锚、准备背包……）。
3. 每个敌人决定并展示**第一个**意图。
4. 进入第一段玩家阵营行动。

### 2.2 玩家阵营 / 角色行动开始

顺序固定，前一步的死亡判定通过后才做下一步：

| 顺序 | 事件 | 谁可以关掉 |
| ---: | --- | --- |
| 1 | 清除自己的格挡 | 路障、模糊 |
| 2 | 行动开始类触发（玩家身上的中毒、恶魔形态、残杀抽牌等） | — |
| 3 | 若玩家已死 → 失败 | 仙灵 / 蜥蜴尾巴可能在扣血时已改写 |
| 4 | 能量重置为上限 | 冰淇淋：跳过重置，保留未用能量 |
| 5 | 抽到手牌目标张数（默认 5，含固有规则只在第一回合特殊） | 「不能抽牌」；符文金字塔不在此时，它改的是结束弃牌 |

中毒若在玩家身上，在第 2 步按当前层数造成生命损失再 -1 层。

### 2.3 玩家角色行动中

玩家可以按任意顺序：

- 打出合法的牌（每次打出是一次完整结算，见 [牌堆流转与打出.md](牌堆流转与打出.md)）
- 使用合法的药水（不耗能量、不计打出张数）
- 点击结束回合（主动结束本段行动）

系统也可以结束这段行动：

| 来源 | 规则 |
| --- | --- |
| 时间吞噬者的时间扭曲 | 本场玩家累计打出 12 张牌后，强制结束当前玩家行动（计数跨玩家的多段行动累计，打出第 12 张的那张仍结算完再结束） |
| 天鹅绒项圈 | 本段行动已打出 6 张则不能再打，但可以喝药、可以点结束 |
| 诅咒「正常」 | 本段最多 3 张 |

「结束玩家行动」必须是规则能触发的命令，不能只存在于 UI 按钮。否则时间吞噬者无法实现。

任意一次结算后玩家生命 ≤0 且无致死改写 → 失败；敌人全灭 → 胜利，不再进入怪物阵营。致死改写时点见 [伤害格挡与生命损失.md](伤害格挡与生命损失.md) 第 7 节。

### 2.4 玩家角色行动结束 → 玩家阵营行动结束

| 顺序 | 事件 |
| ---: | --- |
| 1 | 角色行动结束触发（金属化获得格挡、活动肌肉的力量下降、再生回血……） |
| 2 | 仍在手里的牌做「结束时在手」结算（燃烧伤害、悔恨按**此时**手牌张数失血、怀疑等） |
| 3 | 虚无牌消耗 |
| 4 | 其余未保留手牌弃掉 |

本节只承认上面这一条顺序，不要再写成「先弃牌再结算手里的燃烧」。悔恨与燃烧同一时点、都在弃牌之前，按当时手牌数结算，不会和弃牌后的张数打架。

### 2.5 怪物阵营行动开始

**所有带中毒的怪物在此刻一起结算中毒**（生命损失，然后各 -1 层），不是轮到某只再毒发。

若因此全部敌人死亡 → 胜利，不再执行任何怪物的角色行动。

### 2.6 每只怪物的角色行动

对每个仍存活的怪物，按站位从左到右（或固定编队顺序）：

| 顺序 | 事件 |
| ---: | --- |
| 1 | 清除自己的格挡（路障等例外） |
| 2 | 若处于眩晕 / 意图已不可执行 → 跳过出手 |
| 3 | 执行当前意图（攻击走攻击伤害管线；施加能力走施加规则） |
| 4 | 角色行动结束触发（该怪物自己的金属化等） |
| 5 | **立刻决定并展示下一轮意图** |

第 5 步是意图系统的核心：玩家在接下来整段自己的行动里都能看见敌人下一击。不是玩家回合开始才掷骰。

一只怪物在第 3 步里把玩家打死 → 失败，后续怪物不再行动。

### 2.7 一轮结束

虚弱 / 易伤 / 脆弱等回合型能力统一减 1 层，刚施加保护见 [Buff与Debuff.md](Buff与Debuff.md) 第 4.3 节。

然后进入下一轮的玩家阵营行动开始。没有「双方同时行动」。

## 3. 能量

| 规则 | 默认 |
| --- | --- |
| 上限 | 3，可被 Boss 遗物 +1，可被卡牌本场提高 |
| 每段玩家行动开始 | 当前能量 = 上限（不是 += 上限） |
| 未用完 | 丢弃 |
| 打出 | 当前能量 -= 该牌当前费用 |
| X 费 | 把当前能量全部花掉，X = 花掉的数 |
| 药水 | 不耗能量 |
| 获得能量效果 | 加在当前能量上，本段行动可用；可以超过上限 |

冰淇淋：跳过「当前能量 = 上限」，未用完的能量带到下一段；下一段开始若仍有冰淇淋，是「保留剩余」还是「保留剩余再补到上限」？原版是**完全不重置**，即你剩 2 点就以 2 点开始，不会补到 3，也不会变成 5。额外「获得能量」仍可把当前值加高。

快乐花等「每 N 回合 +1 能量」发生在重置之后，加在已经重置好的当前能量上。

## 4. 抽牌张数与手牌上限的时序位置

默认每段玩家行动开始抽到 5 张（手牌已有保留牌则只抽差额，还是抽满到 5？）。原版是**抽 5 张**，不是「抽到手牌=5」。手里因符文金字塔留了 7 张，再抽 5 会撞手牌上限 10，多的抽不出来。

准备背包：第一回合额外抽 2，发生在常规抽牌时点。

## 5. 强制结束与「额外回合」

- 强制结束玩家行动 ≠ 跳过怪物行动。时间吞噬者让你停手后，仍进入怪物阵营。
- 某些敌人在血线以下会「获得额外一轮行动」（在同一轮结构里插入又一次怪物阵营，或立刻再执行一次角色行动）。需求上「角色行动」必须能被规则再次调度，不能写死「每轮每个敌人恰好一次」。
- 玩家侧「额外回合」（如双动遗物、某些药水）= 再走一遍玩家阵营行动（清格挡与否、抽牌与否按该效果自己写）。默认清格挡仍发生，除非效果声明不清。

## 6. 时点粒度对照（验收用）

| 能力 / 规则 | 正确时点 | 挂错会怎样 |
| --- | --- | --- |
| 清格挡 | 该生物角色行动开始 | 挂到行动结束则防御牌挡不住敌人 |
| 玩家中毒 | 玩家角色/阵营行动开始 | 挂到结束则玩家能先打完再毒发，节奏反了 |
| 怪物中毒 | 怪物**阵营**行动开始，全体一起 | 挂到每只角色开始，则左怪毒死时右怪可能已经出过手，或顺序依赖站位 |
| 金属化 | 该生物角色行动结束 | 挂到阵营结束，多怪物会在错误的时间获得格挡 |
| 虚弱减层 | 一轮结束 | 挂到各自行动结束，1 层易伤无法覆盖「本回合后续出牌」的预期 |
| 能量重置 | 玩家行动开始、清格挡和开始触发之后 | 先抽牌再重置，0 费抽牌类会和能量时序搅在一起 |
| 燃烧牌 | 玩家阵营结束、弃牌流程里 | 挂到角色结束、金属化之前或之后需固定；见 2.4 |

## 7. 对本项目的需求分析结论

- Phase 1 的「玩家回合 → 敌人打一下」是四级时序在 1v1、无中毒阵营差时的退化，不假；一旦多怪物或金属化/中毒并存，必须拆阵营与角色。
- 结束玩家行动是规则命令。
- 能量重置、清格挡、弃手是三扇可被关掉的门，默认全开。
- 意图在敌人自己行动结束时刷新，保证玩家整段行动都能看见下一击。
